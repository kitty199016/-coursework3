# Курсовая работа: Парсер вакансий с HH.ru в БД PostgreSQL

Проект предназначен для автоматизированного сбора данных о работодателях и их вакансиях с публичного API HeadHunter (hh.ru), сохранения этой информации в реляционную базу данных PostgreSQL и последующего анализа вакансий с помощью кастомного менеджера базы данных.

## 🚀 Функционал
- Динамический сбор данных по **10 крупным IT-компаниям** через публичный API HeadHunter без необходимости авторизации.
- Автоматическое создание базы данных и связанных таблиц (`companies` и `vacancies`) с поддержкой связей `FOREIGN KEY` и каскадного удаления `ON DELETE CASCADE`.
- Защита данных от дублирования при повторном запуске скрипта с помощью конструкций `ON CONFLICT DO NOTHING`.
- Аналитический класс `DBManager`, предоставляющий готовый интерфейс для выполнения SQL-запросов (поиск по ключевым словам, расчет средних зарплат, вывод топ-вакансий).
